Firefox setup — everything in one place

Open this page in Firefox. Click each step in order (links use this site automatically).

Before you start — requirements

Firefox desktop · YouTube with captions on · an OpenAI API key (paste it in the LinguaWatch toolbar popup after install — lessons use OpenAI and are billed to your account).

Privacy summary →

Step 1 — Download a ZIP

Choose one package. Save the file when prompted.

LinguaWatch-firefox.zip LinguaWatch-firefox-test-friends.zip

Direct URLs (copy if needed):

Step 2 — Unzip

Unzip so you have a folder containing manifest.json (same folder as the rest of the extension files).

Step 3 — Load in Firefox

Open Firefox’s debugging page for this browser profile:

Open about:debugging (This Firefox)

Click Load Temporary Add-on…, then select manifest.json inside the folder you extracted.

Step 4 — Add your OpenAI API key

Click the LinguaWatch icon in the toolbar → paste your OpenAI API key → save. Without a key, lessons will not generate.

Get a key from OpenAI if you do not have one (normal API pricing applies).

Step 5 — Watch on YouTube

Open YouTube and turn captions on. Pin the LinguaWatch icon from the puzzle menu if needed.

Open YouTube

Note — temporary install

Temporary add-ons are removed when Firefox fully quits. After that, repeat Step 3 onward.

If something goes wrong

Lessons fail or “missing API key” — Open the popup and confirm your OpenAI key is saved.

Extension gone after closing Firefox — Normal for temporary add-ons. Reload from Step 3.

Bad or silly phrases — Captions drive everything; try another video or a cleaner subtitle track.

Download 404 — Confirm this site is deployed and use the copy-paste URLs under Step 1.
